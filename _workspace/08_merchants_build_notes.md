## 아키텍처 — 시도별 지연 fetch (task #9 "반드시" 요건)

`index.html`(file:// 오프라인 전제, 데이터 4MB 번들 인라인)과 달리 merchants.html은 GitHub Pages 서빙 전제 → `fetch` 사용. 데이터가 시도당 1.6~5.8MB(합 ~14MB)라 **시도 선택 시 해당 파일만 지연 fetch하고 캐시**한다(과업 명시 요건).

- 단일 파일 vanilla JS + inline CSS. 프레임워크·외부 CDN 의존 0.
- **시도 탭 서울/인천/경기(전체 탭 없음)**, 기본 서울. 초기엔 `seoul.json` 하나만 로드. 탭 클릭 시 그 시도 파일을 fetch → `CACHE[시도]`에 보관, 재클릭 시 재fetch 안 함.
- 네트워크 검증: 인천 탭 클릭 시 정확히 `incheon.json` 1건만 GET(경기는 미로드 유지). 지연 로드 확인됨.
- 카테고리 칩·검색·집계는 **현재 로드된 시도 파일 안에서만** 계산 → 전 시도를 메모리에 올릴 필요 없음.

## 디자인

index.html 디자인 토큰 재사용(팔레트·칩·탭·표·카드 스타일, 문체)으로 형제 페이지 통일. 폰트는 4MB Pretendard 임베드를 복제하지 않고 동일 스택만 지정(시스템 폴백).

## 기능

- 시도 탭(지연 로드) · 카테고리 칩(전체+6, 건수) · 검색(이름+시장명+취급품목, 150ms 디바운스) · 정렬(기본/이름순) · 디지털 토글 · 페이지네이션(50/페이지, 처음·이전·다음·끝).
- 시도 전환 시 카테고리 '전체'로 리셋. 로드 중 "불러오는 중" 상태 표시.
- 빈 결과(M5): 검색어 되짚기 + 스냅샷 안내 + `검색 초기화` + `앱 가맹점 지도로 확인 ↗`.
- **조용한 실패 금지**: 시도 fetch 실패 시 빈 표가 아니라 "웹 서버에서 열어야 함(file:// 차단)" 안내 + 다시 시도 버튼.
- 색각 안전: 카테고리·'지류만' 배지 모두 **색+텍스트 병기**. 표 `overflow-x:auto`+`min-width:760px`로 격리(body 가로 밀림 없음). `/` 포커스, Esc 초기화.

## 판단이 필요한 자리 (main 확인 요청 — 08 flag)

- **[판단 1] 디지털 필터 — 지시 상충**: 상세 과업(msg1)은 "표시+필터 토글(기본 전체)", 승인 msg2는 "digital Y만 수록(49,719)". 두 지시가 반대라 **토글을 제공하되 기본값을 ON(디지털만)**으로 두어 양쪽을 최대한 충족했다(기본 뷰 = 49,719 기준, 토글 해제 시 지류 포함). 기본값을 OFF(기본 전체, msg1 문자 그대로)로 원하면 한 줄 변경. 각주 ①도 이 절충을 반영("디지털형·지류형 수록, 기본은 디지털만").
- **[판단 2] '전체' 시도·'총 {total}곳' 그랜드 총계**: 콘텐츠 명세 07 M1/M3/D2/D5는 '전체' 칩 + "총 {49,719}곳"을 요구하나, 이는 3파일 전량 로드를 전제한다. 과업의 "반드시 시도별 지연 fetch"와 상충하므로 **전체 탭·그랜드 총계를 뺐고, M1은 현재 시도 건수를 보인다**(예: "서울 22,317곳"). 수도권 총계 표기가 꼭 필요하면 (a) curator가 경량 `counts.json`(시도·카테고리 집계) 추가 → 지연 로드 유지하며 총계 즉시 표기, 또는 (b) 전량 로드 회귀. 권장은 (a). 지시가 오면 반영.
