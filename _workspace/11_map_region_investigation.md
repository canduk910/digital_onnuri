## A. 관측 (라이브, 2026-08-07)

### A-1. 시/도 드롭다운 실제 옵션 = 16개 전체 (직접 열어 확인)
Playwright로 정상 앱을 띄우고 시/도 드롭다운을 실제로 클릭해 렌더된 옵션을 읽음:
`서울, 전남광주, 부산, 대구, 인천, 대전, 울산, 세종, 경기, 강원, 충북, 충남, 전북, 경북, 경남, 제주` (16개)
→ **인천·경기 포함 전국이 모두 UI에 존재.** 3개 제한 아님. (confidence high — DOM 직접 관측)

### A-2. 시/도 목록을 채우는 API = POST /api/v2/onr/addr
- 이 엔드포인트가 드롭다운을 채운다. **POST**이며, GET으로 호출하면 `resCode 9999`(시스템 오류)가 나온다(리드/내가 raw curl에서 겪은 현상의 원인).
- 빈 body(`{}`)로 POST 시 `resCode 0000` + 16개 시도 리스트 반환:
  - `11000 서울 / 12000 전남광주통합특별시 / 26000 부산 / 27000 대구 / 28000 인천 / 30000 대전 / 31000 울산 / 36110 세종 / 41000 경기 / 51000 강원 / 43000 충북 / 44000 충남 / 52000 전북 / 47000 경북 / 48000 경남 / 50000 제주`
- **주목**: 광주(29000)·전남(46000)이 목록에서 사라지고 **"전남광주통합특별시"(12000)** 로 통합됨. 강원(42→51), 전북(45→52) 등 코드 체계도 최신화됨.
- (confidence high — API 응답 직접 재현)

### A-3. 데이터/검색은 전국 정상
- 리드 실측: `/api/v2/onr/addr/{코드}`로 인천(28000)·경기(41000) 구·군 목록 정상 200 응답, 검색창은 부산 등 전국 결과 반환.
- 즉 가맹 DB·주소 상세는 전국. UI도 현재 전국. → 어느 계층에도 "3개 지역" 제한 없음.

### A-4. 사이트 재배포/과도기 정황 (task#15 1차 조사에서 관측)
- onnuri.gift SPA가 최근 재배포됨: 현재 HTML은 `index-ByJZ6i2X.js`(200)를 참조하나, 캐시된 브라우저는 구번들 `index-CWCAkrzB.js`를 계속 로드 → 구번들이 CDN에서 404/503 → 앱 미렌더. **재배포 직후 캐시/번들 불일치로 앱이 깨지는 과도기 상태가 실재**했다(내 크롬 세션에서 재현).

## B. 배경 근거 — 전남광주통합특별시 출범 (주소 대개편의 원인)

- **2026-07-01 전남광주통합특별시 공식 출범** — 대한민국 첫 광역 행정통합. 전라남도(광역)와 광주광역시가 **폐지·통합**, 전남 22개 시군 + 광주 5개 구가 단일 행정체제로 편입.
- 법적 근거: 「전남광주통합특별시 설치를 위한 특별법」(2026-06-24 국회 의결, 국가법령정보센터 lsInfoP lsiSeq=284111).
- 함의: 전국 행정구역 코드/주소 체계가 바뀌는 사건 → **온누리 주소 데이터(addr) 전면 재적재가 최근(약 5주 전) 필요했다.** 실제 API가 광주+전남을 12000 단일 코드로 통합해 반영 중인 것이 그 증거.
- (confidence high — 공식 법령 + 다수 언론 + 관측된 API 데이터가 일치)

## D. 왜 리드는 "3곳(서울·전남광주·부산)"을 봤는가 (추정)

- 관측 시점이 **주소 재적재 + 사이트 재배포 과도기**여서, addr 리스트가 부분만 노출됐거나(앞쪽 코드 11·12·26만), 앱이 degraded 상태로 일부만 렌더됐을 가능성.
- 흥미롭게도 서울(11000)·전남광주(12000)·부산(26000)은 **addrCd 오름차순 앞 3개**다 → 재적재/부분 렌더 시 앞쪽만 채워지는 전형적 과도기 패턴과 부합.
- 지금은 전국 16개가 정상 노출되므로 **이미 해소된 일시적 상태**로 판단. (confidence medium-high — 정황 강하나, 리드가 본 정확한 그 순간의 서버 상태를 내가 직접 캡처하진 못함)
