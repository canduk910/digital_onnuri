## 주장 1 — 오프라인 사용 요건 4가지

### ① 지정 구역(전통시장·상점가·골목형상점가) 안 점포
- 판정: **확인됨**
- 근거: 시행령이 "시장·상점가·골목형상점가 등의 상인"을 대상으로 규정. 정책브리핑·법령 일치.
- confidence: **high**

### ② 온누리 가맹점 등록(스티커/앱 지도 확인)
- 판정: **확인됨**
- 근거: 가맹점 등록제(semas 가맹점 가입안내). 앱 내 사용처(가맹점) 검색 기능 존재(디지털온누리 통합앱).
- confidence: **high**

### ③ 연매출 30억 원 이하 (2026.6.17 신규·3년 갱신 적용, 초과 시 기존 가맹점 말소)
- 판정: **대체로 확인됨 — 단, "기존 가맹점 말소" 서술에 경과조치 누락 (DELTA)**
- 확인 사실:
  - 직전 사업연도 **매출액** 또는 (해당/직전 연도) **온누리상품권 환전액**이 **30억 원 초과** 시 신규 등록·갱신(등록일로부터 3년 주기) 제한. (법령 + 정책브리핑, high)
  - 등록 후 매출 초과·제한업종 해당이 확인되면 가맹점 등록이 **취소**됨. (정책브리핑, high)
- **DELTA(수정 필요)**: 기존 페이지는 "초과 확인 시 기존 가맹점도 등록 말소"만 서술. 그러나 정책브리핑 원문은 **"시행일 이전 등록된 기존 가맹점은 시행 이후 최초 갱신 전까지는 개정된 매출액·업종 기준을 적용받지 않는다"**는 **경과조치**를 명시. → "즉시 말소"가 아니라 "최초 갱신 시점부터 적용"이라는 단서를 반드시 추가할 것.
- confidence: **high** (30억 기준·시행일), 경과조치도 high

### ④ 제외(제한) 업종
- 판정: **확인됨 — 약국 예외는 별도 주의 (부분 DELTA)**
- 확인 사실:
  - 시행령 제9조의16으로 **법무 관련 서비스업, 보건업(병·의원·치과·한의원 등), 사행시설 관리·운영업**을 제한업종에 **추가**. **수의업, 회계·세무 관련 서비스업**도 제한. (법령 + 정책브리핑, high)
  - 대형마트·백화점·기업형슈퍼마켓(SSM/준대규모점포), 유흥·사행성 업종 제외: 종전부터 유지되는 제한(운영 기준). (medium-high — 언론·운영기준 일치, 시행령 조문 직접 인용은 미확보)
  - **약국 예외**: 약국은 전국상인연합회 협의·고령층 의료접근성·집객효과 고려로 **제한업종에서 제외(가맹 유지)**. (언론 다수: 데일리팜·매일일보·파이낸셜뉴스, medium-high)
- **주의(중요 DELTA)**: 약국도 **30억 원 매출 기준은 동일 적용**됨(초과 시 등록 불가/자격 박탈). "약국은 예외적으로 가맹 유지"만 쓰면 오해 소지 → "단, 30억 기준은 약국에도 적용"을 병기할 것.
- **미확인**: 시행령 **조문 본문**에서 약국 예외의 명시 위치(별표/시행규칙 여부)는 원문 확인 미완. law.go.kr 개정이유에는 약국 예외 별도 명시 없음 → 예외 근거가 시행규칙·운영 협의 수준일 가능성. 확정 인용 필요 시 시행령 별표/시행규칙 원문 추가 확인 권장.
- confidence: 제한업종 추가 **high** / 약국 예외 **medium-high**

### ④-보강 — SSM(기업형슈퍼마켓) "불가" 단정은 부정확 (사용자 결함 제보 대응)

관측: onnuri.gift/place에 "지에스더프레시" 14건, data/merchants/gyeonggi.json에도 GS더프레시 2건(광복로골목형상점가·수원아이파크시티8단지상가 골목형상점가, 둘 다 디지털Y·2024 등록). 기존 페이지의 "백화점·SSM ✕ 불가" 단정과 상충.

- **법적 구조 (확인)**:
  - 유통산업발전법 제2조(준대규모점포 정의): 준대규모점포 = ①대규모점포 경영회사 또는 그 계열회사가 **직영**하는 점포, ②상호출자제한기업집단 계열회사가 **직영**하는 점포, ③①·②의 회사·계열회사가 **직영점형·프랜차이즈형 체인사업의 형태로 운영**하는 점포. → 요건의 핵심은 "**대기업 계열회사가 직영/운영**". (조문 구조 확인, high)
  - 온누리 가맹 제외의 표적은 **대규모점포(백화점·대형마트)·준대규모점포(SSM)** = 실무상 **대기업 직영 SSM**. 따라서 **GS더프레시 직영점 = 준대규모점포 = 제외**는 여전히 유효. (high)
- **예외가 성립하는 경로 (관측 정합)**:
  - 온누리 가맹 등록은 **개별 사업자(점포) 단위**이며, 공식 등록요건(ongift.or.kr)은 "① 전통시장·상점가·골목형상점가 등 **지정구역 내 위치** ② **연매출 30억 이하** ③ 제한업종 아님". 
  - **개인 가맹점주가 운영하는 GS더프레시 가맹점(FC)**은 대기업 직영이 아니라 **독립 소상공인 사업자**로 등록되고, 위 지정구역·매출 요건을 충족하면 가맹 가능. 관측된 2건이 모두 **골목형상점가 소속**인 점이 이를 뒷받침. (medium-high)
- **결론 / 원칙 유지 범위**:
  - "SSM 불가"는 **대기업 직영점 기준으로는 유효**하나, **동일 브랜드라도 전통시장·골목형상점가 지정구역에 속한 개인 가맹점(소상공인 사업자)은 가맹 가능**. 갈림의 축은 **브랜드명이 아니라 (a)운영주체 직영/가맹 (b)지정구역 소속 (c)매출 30억**.
  - 2026.6.17부터 매출 30억 기준이 **신규·갱신**에 적용 → 대형 가맹점은 향후 갱신 시 제한 가능(관측 2024 등록분은 최초 갱신 전까지 경과조치 유지).
- **한계/주의 (confidence 조정 근거)**: 유통산업발전법 **영업규제(의무휴업) 맥락**에서는 프랜차이즈형 SSM 가맹점도 준대규모점포로 분류되어 규제받는다는 보도(뉴스1)가 있어, "가맹점=준대규모점포 제외"라고 조문 레벨로 단정 불가. 온누리 등록을 설명하는 것은 준대규모점포 정의 자체보다 **개별 사업자 요건(지정구역·매출·업종)**. 시행령 제9조의16/별표 원문(직영·가맹 경계) 직접 확보 실패(law.go.kr SPA·LBOX 403).
- confidence: 직영점 제외 **high** / 가맹점 등록 가능(개별 사업자 요건) **medium-high** / 조문상 직영·가맹 경계 근거 **medium**
- **writer 권고 문구**: "대형마트·백화점·기업형슈퍼마켓(SSM) **직영점**은 사용 불가. 단, 동일 브랜드라도 **전통시장·골목형상점가에 속한 개인 가맹점**은 가맹된 경우 사용 가능 — 앱 지도에서 개별 확인." ("✕ 불가" 단정 삭제, 계산대 앞 이탈 방지)

## 주장 2 — 카드형 결제 구조(선차감 5단계)

- 단계: 카드 등록 → 충전(할인·월 한도) → 결제 → 선차감 → 앱 알림
- 판정: **대체로 확인됨 — "부족분만 카드 청구" 서술은 재검증 필요 (DELTA)**
- 확인 사실:
  - **충전 할인 + 월 한도** — 2026-08-27 정정: 할인 7%(2026-03-01 시행), **구매(충전)한도 월 100만 원 · 보유한도 200만 원**(2026-01-01 시행 공식 공지). 최초 조사의 "10% 할인·월 200만 원"은 그 시점 값으로 지금은 낡았다. (주장 6 참조)
  - 보유 카드를 앱에 등록 → 앱에 충전 → 등록 카드로 결제 시 **충전 잔액이 먼저 차감(선차감)** (공식몰 onnuri-mall, KB, high)
  - **미가맹점이면 충전액 차감 없이 일반 카드결제 처리** (high)
- **DELTA(재검증)**: 기존 페이지는 선차감을 "**부족분만 카드 청구**"로 서술(=충전액 전액 사용 후 나머지만 카드). 그러나 공식몰(onnuri-mall) 원문은 **"충전한 금액보다 결제할 금액이 크면 충전금 차감이나 병행 결제 없이 일반카드로 한 번에 결제"**라고 설명 → **부분 병행결제가 아니라, 충전 잔액 부족 시 전액 일반결제**일 가능성이 높음. "부족분만 카드 청구"는 실제 동작과 상충할 수 있으므로, 배포 전 공식 앱 FAQ로 반드시 확정할 것.
- confidence: 충전·할인·선차감 개념 **high** / 잔액 부족 시 처리 방식 **medium** (출처 1건, 상충 서술 존재)

## 주장 4 — 모바일(앱)형 결제 구조 (기존 페이지 서술 없음 → 신규 조사)

- 판정: **조사 완료 — 아래 구조 추가 권장**
- 확인 사실:
  - 2025.3.1. 운영사가 비즈플레이 → **한국조폐공사**로 변경되며 기존 분리 운영되던 **모바일형(QR)과 카드형이 단일 앱 "디지털온누리"로 통합**. 종전 모바일 QR은 비플페이 앱, 카드형은 별도 앱이었음. (namu·업계, high)
  - 본인 명의 휴대폰으로 회원가입 → **앱에서 충전**(할인율·한도는 주장 6의 현행 값을 따른다).
  - **QR 결제**: 앱 'QR 결제' 탭에서 가맹점 QR 스캔 후 금액 입력, 또는 내 QR 생성해 점주에게 제시 → 간편비밀번호/지문/패턴 등 인증 → 충전 잔액에서 차감.
  - 하나의 앱에서 QR 결제·카드 결제 모두 가능, 잔액 조회·사용처 검색 포함.
- 권장 서술(5단계 대응): 앱 설치·가입 → 충전(할인·월 한도) → QR 결제(스캔 또는 QR 제시) → 인증·충전잔액 차감 → 앱 알림/잔액 확인
- confidence: **high** (통합·QR 방식) / 세부 인증수단 **medium-high**

## 주장 5 — 정책자금 지급분은 개인 한도에 포함되지 않음 (2026-08-25 추가, 2026-08-27 정정)

- 판정: **고객센터 유선 확인 — 공식 문서 미기재. 어느 한도인지는 미특정**
- 확인 사실:
  - 온누리 고객센터(1670-1600) 유선 문의 결과, **정책자금으로 지급받은 온누리상품권은 개인 한도 계산에 포함되지 않는다.** 지급분이 잔액에 있어도 본인 몫의 충전 여력은 그대로다. (확인일 2026-08-25)

- 근거: 온누리상품권 공식 공지 「2026년 온누리상품권 할인 판매 및 정책 변경 안내」 — 중소벤처기업부·소상공인시장진흥공단 공동 포스터, 2025-12-31 게시, **2026-01-01 시행**. (onnuri.gift/news/notice/detail?no=6, 포스터 원본 2026-08-27 직접 판독)

| 할인율 | 10% *(→ 2026-03-01 공지로 7%)* | 5% |
| **구매한도(월)** | **100만 원** | 50만 원 |
| **보유한도** | **200만 원** | - |

기업고객: 할인율 0%, 구매한도·선물하기 한도 없음.

- **두 한도는 다른 개념이다.** 구매한도 = 한 달에 새로 충전할 수 있는 금액 / 보유한도 = 잔액으로 갖고 있을 수 있는 상한. 잔액이 200만 원에 차 있으면 그 달 구매한도가 남아도 충전할 수 없다.
- **낡은 출처 경고**: onnuri.gift FAQ의 "디지털 온누리상품권 충전 한도가 있나요? → 월 최대 200만 원"은 2026-08-27 현재까지 갱신되지 않았다. SEMAS '구매 및 사용안내'의 구매한도 표(개인 카드형·모바일 월 200만원)도 같다. **둘 다 인용하지 않는다** — 정책 변경 공지가 상위 근거다.
- **이전 조사의 오판 기록**: 2026-08-11 채록 때 소진공 안내에 보이던 "월 100만 원"을 구식으로 보고 200만 원을 채택했고, 2026-08-25 재확인 때도 웹 검색에 나온 100만 원을 "2차 자료"라며 기각했다. 두 번 다 판단이 반대였다. 원인 — 공식 FAQ·SEMAS 표(3순위 출처)만 보고 **공지(2순위)를 끝까지 읽지 않았다.** 공지가 이미지(포스터)라 "이미지 공지는 제목만 기록" 원칙에 걸려 본문을 열지 않은 것이 결정적이었다. 이미지 공지라도 **정책 수치가 걸려 있으면 원본을 내려받아 판독한다.**
