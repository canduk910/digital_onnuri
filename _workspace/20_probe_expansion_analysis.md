# 20. 실시간 조회 확대 — 남은 12곳에 쓸 수 있는 기법 전수 검토

**조사일 2026-09-02.** 조회 대상 10곳(ADR-17, 19_online_probe 6-8절) 이후 "확인하지 않는 12곳"을 더 열 방법이 있는지 묻는 요청. 크롤링 기법을 전부 올려놓고 12곳 각각에 대입했다. 결론은 ADR 후보로 마지막 절에 둔다.

---

## 0. 먼저 바로잡을 것 — 12곳의 사유가 화면과 다르다

화면은 "robots 차단 2곳 · 화면에서만 만들어져 읽을 수 없음 10곳"이라고 말한다. `ProbeTargets.EXCLUSION` 이 굿데이·인더마켓 2곳만 robots 로 적고 **나머지를 전부 `no-static-search` 기본값으로 흘리기 때문**이다. 6-6·6-7절의 조사 결과를 사전에 반영하지 않았다. 실제 분류는 이렇다.

| 구분 | 몰 | 실제 상태 |
|---|---|---|
| **robots 차단 (기술적으론 됨)** | 온누리굿데이 · 인더마켓 · 온누리팔도시장 | 정적 조회 **성공 실측**(굿데이 31/0, 인더마켓 33/0, 팔도 60/2). `Disallow: /`·`/Goods/` 라서 안 한다 |
| **robots 차단 (SPA 이기도 함)** | 11번가 · 현대홈쇼핑 · 롯데ON | `Disallow: /` (11번가 `Crawl-delay: 1`, 롯데ON 3). 롯데ON 은 범위 오염까지 |
| **robots 가 검색 경로만 차단** | 사이소(`/api/`, 화면은 WAF 1.7KB) · 공영쇼핑(`/search/`·`/api/`) | 내부 API 도 화면 검색도 금지 |
| ~~검색 기능 자체가 없음~~ → **정적 검색 실존(2026-09-02 정정)** | 지니어스몰 | 기본 URL 4변형은 실패했으나 목록 페이지 폼의 `name="search"` 로 검색됨(`/product/product.html?search=`, 12건/0건). robots 허용 → **실시간 11번째 대상으로 승격** |
| **검색은 있으나 범위가 먼저** | 온누리 놀장(시장 선택 → `/market/{id}` 안에서 검색) · 시장을 방으로(배달 주소 선택 → `/shop/address.php`) | 전역 검색이 없다 |
| **검색 API 는 있으나 인증** | 인어교주해적단 | `api.tpirates.com/v3/www/product/search` 실존, **`onnuri` 필터 키까지 있음** — 직접 호출은 401 |

즉 **12곳 중 8곳은 브라우저를 들여도 열리지 않는다** — robots(8) 아니면 범위 선행(2)이 막고 있고, 브라우저가 실제로 여는 건 인어교주해적단 1곳이다(지니어스몰은 정정 후 정적 조회로 열린다). "화면에서만 만들어진다"는 문구는 12곳 중 어디에도 정확히 맞지 않는다. **화면 문구와 사유 사전을 먼저 고쳐야 한다**(4절 A안 — 코드 몇 줄).

수집 계층(응답을 어떻게 얻나)과 색인 계층(미리 모아 두나)으로 나눈다. 각 기법에 "이 프로젝트에서 여는 곳 수"를 적었다 — 기법의 화려함이 아니라 이 숫자가 판단 기준이다.

## 3. 왜 브라우저가 답이 아닌가 (ADR-17 ⑧ 재평가)

ADR-17 이 기각한 것은 "요청마다 크롬을 띄우는" 방식이고, 웜 풀 사이드카는 다르다 — 이미 배치 D 가 같은 서버에 Chromium 을 두고 있다. 그러니 기술적으로는 **할 수 있다.** 그런데 대입표가 보여 주듯 브라우저가 실시간으로 여는 곳은 **1곳(인어교주)** 이고, 그 1곳도 B1 sitemap 색인으로 상품명의 대부분을 얻는다. 나머지는 robots 가 막거나 전역 검색이 없다. **병목은 렌더링이 아니라 허락과 범위다.** 2 vCPU 에 상주 프로세스를 하나 더 얹는 결정은 A4 단독으론 정당화되지 않고, B2(야간 크롤이 이미 브라우저를 쓴다)와 묶을 때만 이야기가 된다.

robots 를 넘는 선택지(A6·A8·A9, 또는 robots 무시)에 대해서는 사실만 적는다. 국내 판례는 갈린다 — 야놀자·여기어때 사건(대법원 2022, 형사 무죄·민사 손해배상 인정), 잡코리아·사람인(크롤링 금지·손해배상). 정보통신망법 48조의 "정당한 접근권한" 판단에 robots 가 직접 근거는 아니지만 **접근 거부 의사의 증거**로 쓰인다. 이 가이드는 코스콤 이름으로 나가고 페이지가 공개 저장소다. 6-2절이 세운 "되는 것과 해도 되는 것은 다르다"를 유지한다.

## 4. 제안 — 단계와 순서

| 단계 | 내용 | 여는 곳 | 크기 |
|---|---|---|---|
| **A. 사유 정정**(즉시) | `EXCLUSION` 사전에 robots 6곳·범위선행 사유 추가, 화면 문구를 사실에 맞춤(0절). 계약 테스트로 사유↔조사표 일치 고정 | 0 (정직해짐) | 코드 수십 줄 |

**색인 층의 약속 문구**는 실시간과 달라야 한다 — "어제 이 몰이 이 이름의 상품을 올려 두고 있었다"이지 "지금 있다"가 아니다. 계산대 기준(결제 실패 방지)에서 색인은 "가 볼 만한 곳"까지만 말하고, 결제 가능 여부는 각주 그대로 둔다.
