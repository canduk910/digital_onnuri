# 19. 온라인 실시간 조회 — 실현성 조사와 판정 근거

**조사일 2026-08-31.** 온라인 사용처 키워드 검색이 "삼성전자 비스포크 로봇청소기" 같은 상품명에 답하지 못하는 문제(태그 기반 `indexOf` 단일 부분문자열이라 공백이 들면 무조건 0곳)를 실시간 조회로 풀 수 있는지 실측했다. 결론과 설계는 ADR-17.

이 문서는 **코드보다 먼저 쓰인다.** 여기 적힌 실측값이 `ProbeTargets`의 규칙과 테스트 픽스처의 근거이며, 몰이 개편되면 이 표와 실제가 어긋나는 것으로 드러난다.

## 1. 22곳 실현성 조사

`app` 컨테이너는 `eclipse-temurin:21-jre` — 브라우저가 없다. 따라서 **정적 HTTP 응답에 검색 결과가 실리는 몰만** 실시간 조회 대상이 된다. 22곳 홈에서 검색 폼을 추출하고, 추출된 곳에 실제 검색 요청을 보내 판정했다.

## 2. robots.txt 검토 (2026-08-31)

저장소에 robots.txt를 검토한 기록이 없었다. 이번에 처음 확인했고, **그 결과로 2곳을 제외했다.**

| 몰 | robots.txt | 검색 경로 | 판정 |
|---|---|---|---|
| onnuri-hotdeal | `Allow: /` + `Disallow: /api/, /checkout/komsco-return` | `/search` | **허용** |
| onnuri-chance | `Disallow: /include/` | `/` | **허용** |
| onnuri-sijang | HTTP 404 (파일 없음) | — | **명시적 금지 없음** |
| onnuri-market | `User-agent: *` `Allow: /` | `/shop/search_product.php` | **허용** |
| onnuri-gonggong-mall | 그누보드 계열 다수 Disallow(`/adm/ /bbs/ /shop/cart.php` 등) — **`/shop/search.php`는 목록에 없음** | `/shop/search.php` | **허용** |
| epost-mall | `Disallow: /upload/, /*file*, /*File*, /*adm*` | `/fo/search/search.do` | **허용** |
| **onnuri-goodday** | **`Disallow: /` + `Allow: /$`** | — | **차단 — 제외** |
| **inthemarket-onnuri** | **`Disallow: /` + `Allow: /$`** | — | **차단 — 제외** |

`Disallow: /` + `Allow: /$` 는 **홈 문서 하나만 허용하고 나머지 전부 차단**이라는 뜻이다. 기술적으로는 검색이 되지만 조회하지 않는다.

**런타임 robots 조회는 하지 않는다** — 이용자 요청마다 robots.txt를 함께 받으면 아웃바운드가 2배가 되어 부담 억제 목표에 역행한다. 대신 야간 배치가 하루 1회 재조회해 변화만 리포트한다.

## 3. 판정 근거 — 왜 키워드 카운트로는 안 되는가

### 검색어 에코가 상품으로 오인된다

7개 몰 × 4개 질의로 재봤다. 응답에 검색어가 있다고 상품이 있는 것이 아니다.

| 질의 | 몰 | 토큰 히트 | 실제 |
|---|---|---|---|
| 삼성전자 비스포크 로봇청소기 | onnuri-goodday | 1 · 1 · 1 | **에코만** — `"비스포크 로봇청소기 검색결과"` 제목에 검색어가 박혔다. 상품 없음 |
| 삼성전자 비스포크 로봇청소기 | onnuri-gonggong-mall | 3 · 2 · **29** | 실제 상품 다수 |
| 삼성전자 비스포크 로봇청소기 | onnuri-market | 0 · 0 · 0 | 진짜 없음 |
| 다이슨 청소기 | onnuri-hotdeal | **21** · 7 | 실제 상품 |
| 다이슨 청소기 | onnuri-market | 0 · 0 | 진짜 없음 |
| 로보락 큐레보 | onnuri-gonggong-mall | 4 · 1 → `로보락 로봇청소기 호환 리필 물걸레 S5Max` | **부분 매칭 오탐** — 본체가 아니라 소모품 |

**"0이면 없다"는 신뢰할 수 있고, "0이 아니면 있다"는 신뢰할 수 없다.** 이 비대칭이 설계의 축이다. 히트 1~3은 에코 구간, 20회 이상은 실제 상품일 가능성이 높지만 경계는 몰마다 다르다.

### 다중 토큰 질의는 각 몰 검색엔진이 받아준다

"삼성전자 비스포크 로봇청소기"처럼 공백이 든 질의도 대부분 토큰 OR/부분 매칭으로 처리된다. 즉 **검색어를 우리가 쪼개 보낼 필요가 없다.** 다만 그래서 오탐(소모품·유사품)이 늘어난다.

## 4. "결과 없음" 문구 사전 (2026-08-31 실측 원문)

존재하지 않는 키워드(`zzqqxyw12345`)로 조회해 각 몰의 없음 문구를 수집했다. **이것이 판정 1순위 신호다.**

### 등급 A — 검색어 바인딩형 (단독으로 `none` 확정)

문구 안에 검색어가 들어가므로 약관·푸터가 구조적으로 걸릴 수 없다.

| 몰 | 실측 원문 |
|---|---|
| onnuri-hotdeal | `"zzqqxyw12345" 검색 결과 검색 결과가 없습니다` |
| onnuri-sijang | `검색하신 ' zzqqxyw12345 '에 대한 검색결과가 없습니다` |
| onnuri-gonggong-mall | `'zzqqxyw12345' 에 대한 0 개의 검색결과` / `등록된 상품이 없습니다` |

`onnuri-sijang`이 따옴표 안쪽에 공백을 넣는다(`' zzqqxyw12345 '`). 정확 일치로 매칭하면 깨지므로 **토큰 사이 `\s*`를 허용하는 유연 매처**로 컴파일해야 한다.
`onnuri-gonggong-mall`은 건수를 명시(`0 개의 검색결과`)해 가장 견고하다.

### 등급 B — 검색어 비의존형 (단독 확정 금지)

| 몰 | 실측 원문 |
|---|---|
| epost-mall | `고객님께서 찾으시는 검색결과가 없습니다` / `해당하는 상품이 없습니다` |

문구 매치 **+ 토큰 카운트 임계 미만**일 때만 `none`으로 친다. 둘이 어긋나면(문구도 있는데 상품 신호도 강함) `unclear` + 경고 — 몰이 "결과 없음" 배너를 상시 노출하도록 개편된 신호다.

### 등급 C — 사전을 두지 않음

| 몰 | 이유 (실측 원문) |
|---|---|
| onnuri-chance | 명시적 없음 문구가 검출되지 않았다. 잡힌 것은 `원산지 데이터 없음` — 상품 영역 밖 필터 UI 문구라 채택 불가 |
| onnuri-market | ⚠ **검출된 것이 전부 이용약관 문구다** — `③ 적립금은 현금으로 환급될 수 없습니다`, `다만 "몰"이 고의ㆍ과실이 없음을 입증한 경우에는 그러하지 아니합니다`. 페이지 전체에 문자열 매칭하면 **항상 "없음"으로 판정된다** |

`onnuri-market` 사례가 이 저장소가 반복해서 경계해 온 **"에러 없이 다른 답"**의 전형이다. 이 두 곳은 사전을 비워 두고 토큰 카운트로만 판정하며 신뢰도를 낮게 표시한다.

## 5. 상품명 추출 — 몰별 파서가 필요하다

범용 링크 패턴(`href`에 product/goods/item/prd 포함 + 링크 텍스트)으로 3개 몰을 시도했으나 **전부 0건**이었다. 마크업이 제각각이다.

키워드+가격이 같은 줄에 있는 스니펫 방식은 `onnuri-hotdeal`만 잘 나온다.

```
[로보락] Qrevo Edge 2 로봇청소기 · 공구의거리 · 30% · 1,190,000원
에브리봇 침구로봇청소기 X1 · 안양호계종합시장 · 10% · 269,000원
에브리봇 2026년 신상 로봇청소기 Q3 Turbo Plus · 안양호계종합시장 · 20% · 399,000원
[JONR] 로봇청소기 올인원 자동세척 건조 스테이션 T5 Pro Gen 2 · 공구의거리 · 499,000원
```

나머지 3곳은 0건. 따라서 **상품명 추출은 몰별 정규식이 필요하고, 그건 ADR-6이 기각한 "구조 변경에 취약"에 해당한다.**

→ 그래서 상품명 추출을 **판정 경로 밖에** 둔다. 깨져도 "근거 없는 `likely`"로 품질만 떨어지고 오답이 되지 않는다. 자세한 것은 ADR-17.

## 7. 재조사 방법

이 문서의 표는 시간이 지나면 낡는다. 재조사는 카나리아(`/api/online/search/selftest`)가 매일 자동으로 하고, 전면 재조사가 필요하면 다음 순서로 한다.

1. 22곳 홈 HTML에서 `<form>` 중 검색 폼 추출(action + input name)
2. 추출된 URL 템플릿으로 "실제 키워드"와 "없는 키워드"를 각각 조회
3. 태그 제거 후 키워드 히트·응답 길이차 비교 → 실현성 판정
4. 없는 키워드 응답에서 "없습니다/없음/찾을 수 없" 주변 문장 수집 → 문구 사전 갱신
5. robots.txt 재확인 → 차단된 몰 제외
6. `ProbeTargets`와 이 문서를 함께 갱신하고 `measuredOn`·`robotsCheckedOn`을 올린다
