# 13. 빈도+지점명 기반 브랜드 자동탐지 리포트

- 작성: onnuri-data-curator
- 작성일: 2026-08-08
- 산출물: `_workspace/13_brand_candidates.csv` (후보 453종 = 확정 169 / 제외 284) + data 3파일 brand 필드 재산출
- 스크립트: `_workspace/dev_scripts/build_region_full.py` (탐지 로직 통합, 멱등 재실행)

## 0. 반영 범위 (동결 해제분)

team-lead가 이 작업만 동결 해제 → **data/merchants/{seoul,incheon,gyeonggi}.json의 brand 필드를 실제 재산출**했다. 기존 4값(convenience/mart/ssm/daiso)을 **개별 브랜드명 체계로 대체**. 다른 필드·다른 파일은 불변.

## 1. 방법 (사용자 확정 알고리즘)

1. **상호명 정규화** — 괄호 제거, 공백·영문 케이스 통일
2. **지점표기 분리로 base 추출** — '…점'으로 끝나면 지점명. 공백형("CU 상동점"→CU) + 붙임형("GS25포곡점"→접두 매칭, 상호 82%가 단일 토큰이라 필수). 비지점 상호는 정규화 전체 상호가 base(동일 상호 빈도 집계)
3. **빈도 집계** — base별 건수. 7회+ 후보
4. **지점명 비율**(핵심 판별자) — base 멤버 중 '…점'으로 끝나는 비율. **≥40%면 브랜드 확정, <40%면 일반상호 제외**
5. **표기변형 병합** — 씨유=CU, 지에스25=GS25, 파리바게트=파리바게뜨, 지에스더프레시=GS THE FRESH=GS더프레시, 아성다이소=다이소 등(수동 매핑 + 정규화). 붙임형 변형도 접두 앵커로 병합
6. **brand 필드 재산출** — 확정 브랜드명 부여 or null

법인어(주식회사·(주)·농협 등)는 base 블랙리스트로 제외.

## 4. 경계 사례 — 사람 검토 대상 (CSV `경계사례`=Y)

임계 인접(빈도 7~10 또는 지점비율 30~50%)이라 자동판정이 불안정한 사례. 시트 검토로 확정 권고:

- **이디야 31(42%)** 확정됐으나 **이디야커피 17(100%)** 별도 확정 → 표기 분할, 병합 필요.
- **본죽&비빔밥 32(81%)·본죽앤비빔밥 14(71%)** 확정, **본죽 11(27%)** 제외 → 동일 브랜드 3표기 분산, 병합 필요.
- **김밥천국 52(21%)** 제외 — **실제 체인이나** 가맹점이 '점' 표기를 안 써 지점비율이 낮음. 지점명 휴리스틱의 한계 사례로, 사람이 브랜드로 승격할지 판단.
- 유사: 한솥도시락 11(64%)·국수나무 15(67%)는 확정됐으나 표본이 작아 재확인 권장.

전체 경계 표시는 CSV `경계사례` 열(Y) 참조.

## 5. 후보 CSV

`_workspace/13_brand_candidates.csv` (UTF-8-BOM, 453행). 열:

| 열 | 내용 |
|----|------|
| 브랜드명 | 표준 브랜드명(변형 병합 후) |
| 총건수 | 귀속 점포 수 |
| 지점명비율 | '…점' 비율(0~1) |
| 표기변형목록 | 병합된 이표기(예: "지에스 25; 지에스25") |
| 대표주소예시 | 표본 주소 1건 |
| 판정 | 브랜드 / 제외 |
| 판정근거 | "빈도 N·지점비율 M% ≥/<40% → …" |
| 경계사례 | Y(7~10건 또는 30~50%) / 공란 |

스프레드시트로 올려 사람이 판정·병합을 검토하고, 그 결과로 brand를 재확정하는 워크플로.

## 6. 한계

- **지점명 휴리스틱의 미검출**: '점'을 안 붙이는 체인(김밥천국·본죽 일부)은 제외로 떨어짐 → CSV 검토로 보완.
- **표기 분할**: 변형 맵에 없는 이표기는 분산(이디야/이디야커피, 본죽 3형). 수동 매핑 확장으로 병합.
- 임계 7·40%는 스크립트 상수로 조정 가능. 낮추면 소규모 체인↑·노이즈↑.
- 브랜드 필드는 파생 휴리스틱 결과 — 최종 정본은 CSV 사람 검토 후.

## 7. 재실행

```bash
python3 _workspace/dev_scripts/build_region_full.py            # 캐시 재사용, brand 재산출 + CSV 재생성
python3 _workspace/dev_scripts/build_region_full.py --refresh  # API 재수집 후
```

MIN_FREQ·MIN_BRANCH_RATIO·VARIANT_MAP·BLOCK_BASE는 스크립트 상단 상수. 검토 결과 병합·승격은 VARIANT_MAP/화이트리스트에 반영해 재실행.
