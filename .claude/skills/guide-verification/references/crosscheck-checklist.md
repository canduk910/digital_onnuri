## B1. 출처 → 데이터

왼쪽: 온누리 공식 홈페이지 '온라인 전통시장관' / 오른쪽: `data/*.json`

- [ ] 공식 목록의 **전 페이지**를 확인했는가 — `meta.pages_checked`와 실제 사이트의 총 페이지 수를 대조
- [ ] 공식 목록에 있는데 데이터에 없는 항목 (누락)
- [ ] 데이터에 있는데 공식 목록에 없는 항목 (제휴 종료 미반영 → `status: ended` 처리되었는가)
- [ ] `summary`가 출처 사이트 문구와 일치하는가 — 각색되면 사실이 미묘하게 바뀐다
- [ ] `region_limited`가 true인 항목의 지역 정보가 출처와 일치하는가
- [ ] 모든 항목에 `source_url`이 있는가

> 접근 실패로 확인하지 못했다면 **미검증**으로 기록한다. 통과가 아니다.

## B2. 데이터 → 렌더

왼쪽: `data/*.json` / 오른쪽: `index.html`이 그린 화면

- [ ] 온라인 플랫폼: `status === 'active'` 항목 수 == 표에 그려진 행 수
- [ ] 헤더 요약 숫자(총계·쇼핑·배달)가 **하드코딩이 아니라 계산식**인가 — 소스에서 확인
- [ ] 요약 숫자 == 실제 행 수 (화면에서 센다)
- [ ] 업종 표: 항목 수 == 행 수, 카운트 칩 == `verdict`별 집계
- [ ] `verdict_label`이 화면에 텍스트로 렌더되는가 (색·기호만으로 구분하지 않는가)
- [ ] `conditional` 항목마다 `check_point`가 화면에 표시되는가
- [ ] 데이터에만 있고 화면에 안 나오는 필드가 있는가 (의도적인가)
- [ ] 화면에 있는데 데이터에 없는 값이 있는가 → **하드코딩 의심**

> 마지막 항목이 가장 중요하다. 화면에만 존재하는 값은 다음 갱신에서 반드시 거짓이 된다.

## B3. 정책 → 문구

왼쪽: `_workspace/01_policy_analysis.md` / 오른쪽: 페이지 본문

- [ ] 페이지의 모든 요건 서술이 정책 분석의 요건과 1:1로 대응하는가
- [ ] **시행일이 정확한가** — 페이지에 적힌 날짜와 정책 분석의 시행일 대조
- [ ] 시행일과 **적용 시점**(언제 심사되는가)이 함께 서술되는가 — 빠지면 정반대 오해를 낳는다
- [ ] 문장의 단정 강도가 `confidence`를 넘지 않는가

  | confidence | 허용 어조 | 위반 예시 |
  |-----------|----------|----------|
  | high | 단정 | — |
  | medium | 조건 명시 | "반드시 사용 가능합니다" |
  | low | 확인 지시 | "사용할 수 있습니다" |

- [ ] `confidence: low` 항목이 단정형으로 쓰이지 않았는가 (**치명 등급**)
- [ ] confidence가 high인데 과잉 방어("~일 수도 있습니다")로 쓰이지 않았는가
- [ ] 제외 업종 목록이 정책 분석과 일치하는가 (약국 예외 등 단서 포함)
- [ ] "현재", "최근", "곧" 같은 상대 시점 표현이 없는가
- [ ] 업종 판정의 `basis` 요건이 실제로 존재하는 요건 ID인가

## B4. 수집일 → 스탬프

왼쪽: `data/*.json`의 `collected_on` / 오른쪽: 페이지 "○○ 기준" 표기

- [ ] 페이지 스탬프 ≤ `min(items[].collected_on)`
- [ ] 스탬프가 계산식인가, 상수인가 — 상수면 결함
- [ ] `_workspace/02_data_report.md`에 접근 실패 기록이 있는데 **모든 항목의 `collected_on`이 동일**한가 → 확인하지 않은 항목까지 날짜를 올린 것 (**치명 등급**)
- [ ] 이번 실행에서 데이터가 변경되었는데 스탬프가 그대로인가
- [ ] 데이터는 변경 없는데 스탬프만 올랐는가

> 마지막 두 항목은 반대 방향의 같은 결함이다. 둘 다 잡는다.

## 렌더 동작

브라우저로 `index.html`을 실제로 열어서 확인한다.

- [ ] 콘솔 에러 0건 — 에러가 있으면 표가 비어 있지 않은지 반드시 확인
- [ ] 검색: 일치하는 키워드로 필터링되는가
- [ ] 검색: 결과 없음 상태에 검색어 되짚기 + 초기화 경로 + **다음 행동 안내**가 있는가
- [ ] 구분 칩 필터(쇼핑/배달) 동작
- [ ] 정렬 동작, 정렬 후 표시용 연번이 다시 계산되는가
- [ ] 좁은 폭(360px 내외)에서 표가 읽히는가
- [ ] 좁은 폭에서 **body가 가로로 밀리지 않는가** — 표만 자기 컨테이너에서 스크롤
- [ ] 외부 링크가 유효한가 (샘플 확인)

## 리포트 작성 전 최종 확인

- [ ] 모든 결함에 **왼쪽·오른쪽 관측값**이 기록되었는가 ("이상함" 금지)
- [ ] 경계면 결함이 **양쪽 담당자 모두**에게 배정되었는가
- [ ] 미검증 항목과 통과 항목이 섞이지 않았는가
- [ ] 판정(통과/조건부 통과/불합격)이 명시되었는가
- [ ] 치명 결함이 하나라도 있으면 판정은 **불합격**인가
